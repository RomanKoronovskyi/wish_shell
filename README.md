## Висновок

В ході виконання роботи, мовою C++ було реалізовано інтерпретатор командного рядка (CLI) або, як його частіше називають, оболонку. Коли користувач вводить команду, оболонка створює дочірній процес, який виконує введену команду, а потім запитує подальший ввід даних від користувача після завершення. 
У процесі розробки було реалізовано та протестовано повний комплекс функціональних можливостей, таких як два режими функціонування: інтерактивний та пакетний режими, вбудовані команди, такі як механізми виконання cd (зміна робочої директорії через chdir), path (динамічне керування та повний перезапис шляхів пошуку бінарних файлів) та exit (коректне завершення роботи), які виконуються безпосередньо в батьківському процесі без створення дочірніх гілок. Було реалізовано пошук виконуваних файлів шляхом динамічної перевірки наявності та прав доступу до бінарних програм. Також було реалізовано перенаправлення виводу (>) та паралельне виконання команд (&).
Розроблена оболонка успішно проходить тестування, що підтверджує виконання усіх 22 автоматизованих тестів.
